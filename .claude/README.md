# ModelMesh Fast Claude Code Setup

Detailed specifications are preserved, but separated from always-loaded execution rules.

- `CLAUDE.md` — short controller
- `routing/` — task-to-context routing
- `workflows/` — scoped procedures
- `state/` — current state + ownership
- `specs/` — deep specifications, on demand
- `tracks/` — Android parallel tracks
- `archive/` — historical handoff/logs

Goal: reduce repeated context loading, repository-wide inspection, unnecessary test runs, and architectural re-analysis.
